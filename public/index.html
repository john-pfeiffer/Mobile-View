  • The iframe's viewport is set to the device's exact CSS pixel size, so responsive breakpoints and media queries fire the same way they would on the real device.
  • DPR (device pixel ratio) is shown for reference only — it affects image sharpness, not layout width.
  • Sites that block embedding (X-Frame-Options / frame-ancestors) are detected automatically and routed through a server-side proxy. The proxy fetches anonymously — no cookies ever pass through — so logged-in views won't render, and heavy client-side apps may not fully work.

ABOUT

Mobile_View is a small, static tool for checking how a page looks across real device sizes — no build step, no server, no tracking. Pick a preset or add your own, then share the resulting link so everyone reviewing a design is looking at the same frame.
